## 🎬 Recording Tips

1. **Speak clearly** - Not too fast
2. **Use cursor** - Point at features in plots
3. **Show code briefly** - Don't read every line
4. **Focus on visuals** - Let plots tell the story
5. **Stay on time** - Use phone timer
6. **Be enthusiastic** - Show interest in findings
7. **Natural tone** - Be conversational
